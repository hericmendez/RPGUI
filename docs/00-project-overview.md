# Project Overview

## What is RPGUI Modern?

RPGUI Modern is a modern React and TypeScript reimplementation of the RPGUI visual framework.

Its purpose is to bring the distinctive old-school RPG interface aesthetic of RPGUI to modern web applications without carrying forward the limitations of its original implementation architecture.

The project combines:

- pixel-art UI;
- RPG visual language;
- modern React;
- TypeScript;
- accessible interaction;
- responsive layouts;
- SSR compatibility;
- modern package distribution.

## Core Principle

> Classic RPG aesthetics without legacy web architecture.

The project should feel familiar to users of the original RPGUI while being designed for current React development.

## Original Reference

The original implementation is stored at:

```text
original/RPGUI/
````

It is preserved for:

* visual comparison;
* behavioral analysis;
* asset reference;
* feature discovery;
* migration planning.

It is not a runtime dependency.

## Compatibility Philosophy

RPGUI Modern prioritizes:

1. visual compatibility;
2. behavioral compatibility;
3. conceptual compatibility.

It does not prioritize:

1. DOM compatibility;
2. CSS class compatibility;
3. imperative JavaScript API compatibility.

## Initial Component Scope

The initial implementation should cover the most important concepts of the original RPGUI:

* containers;
* frames;
* buttons;
* form controls;
* checkboxes;
* radio buttons;
* select/dropdown;
* listbox;
* sliders;
* progress bars;
* icons;
* cursors where technically appropriate.

Modern RPG-oriented components can then build on this foundation.

## Long-Term Vision

The long-term goal is to provide a reusable RPG UI design system for:

* game websites;
* game dashboards;
* character builders;
* inventories;
* game journals;
* retro-themed applications;
* interactive portfolios;
* RPG-inspired productivity tools;
* fictional interfaces;
* creative web projects.

The library should remain a UI library rather than becoming a game engine or application framework.
