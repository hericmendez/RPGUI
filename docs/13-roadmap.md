```markdown
# Roadmap

The roadmap is intentionally incremental.

## Phase 0 — Original Analysis

- inspect original repository;
- inventory components;
- inventory assets;
- identify behavior;
- identify legacy implementation;
- document licensing/provenance;
- create feature mapping.

## Phase 1 — Project Foundation

- initialize TypeScript;
- initialize React;
- configure Vite;
- configure Vitest;
- establish source structure;
- establish package structure;
- establish lint/typecheck/build.

## Phase 2 — Design System Foundation

- design tokens;
- typography;
- spacing;
- colors;
- surfaces;
- frame primitives;
- asset strategy.

## Phase 3 — Pixel Rendering

- image rendering;
- scaling strategy;
- frame rendering;
- textures;
- icons;
- cursor strategy.

## Phase 4 — Core Components

Implement the essential UI primitives:

- container;
- frame;
- button;
- input;
- checkbox;
- radio;
- select;
- listbox;
- slider.

## Phase 5 — Progress System

Implement:

- RPGProgressBar;
- RPGHealthBar;
- RPGManaBar;
- RPGStaminaBar;
- RPGExperienceBar.

Establish shared resource-bar architecture.

## Phase 6 — Themes

- original-inspired theme;
- theme tokens;
- variants;
- custom theme strategy.

## Phase 7 — Advanced RPG Components

Potential components:

- tooltip;
- dialog;
- item slot;
- inventory;
- stat;
- character card;
- RPG menus.

## Phase 8 — Framework Compatibility

Validate:

- Vite;
- Next.js;
- SSR;
- hydration;
- TypeScript;
- npm;
- pnpm;
- Yarn.

## Phase 9 — Quality

- accessibility audit;
- test coverage;
- visual regression;
- bundle analysis;
- package inspection.

## Phase 10 — Release

- finalize README;
- finalize migration guide;
- verify license;
- verify package;
- publish first release.

## Important

Do not implement future phases prematurely.

Each phase should establish a stable foundation for the next one.
````
